# Calendario orario Ingegneria dell'Energia

Calendari `.ics` generati dall'orario EasyStaff dell'Università di Padova.
Ogni mattina un job li aggiorna nella cartella `docs/`, pubblicata con GitHub Pages.

- `docs/calendario-completo.ics`: tutte le materie
- `docs/<codice>-<materia>.ics`: una materia per file

Se il job fallisce (sito cambiato o non raggiungibile), GitHub manda una mail
e i file precedenti restano invariati.
